## Features in Detail

### 📊 Session Tracking
- Tracks which questions you've answered **within the session**
- Shows running score: `4/10 correct (40%)`
- Avoids repeating questions in the same session
- Resets when you start a new quiz or change units

### 🎯 Unit Filtering
Filter by focus area:
- **Unit 1:** Foundations (65 Q)
- **Unit 2:** Personal Development (147 Q)
- **Unit 3:** Social Values (81 Q)
- **Unit 4:** Professional & Global (120 Q)
- **Unit 5:** Application (102 Q)

### 💡 Memory Tricks
Each answer includes:
- **Core concept** (concise, aligned to your learning style)
- **Why this matters** (context)
- **Memory device** (mnemonic or visual anchor to help retention)

Example: *"Think of SEWA: Selfless, Service, Everyone—that's the heart of Sikh values."*

### ⚙️ Adjustable Explanations
- **Default:** Concise explanations (your preference)
- **"Explain more":** Go deeper with examples and context
- **"Shorter":** Get just the key concept

### 📈 Real-Time Progress
- Score displayed after each answer
- Session total shown at the end
- Percentage accuracy calculated
- Know exactly which units need review

## Pro Tips for Learning

### 🎯 Best Practices
1. **Unit focus** — Study one unit per session (better retention)
2. **Review weak units** — If you score <70% on a unit, revisit it in 24 hours
3. **Explain more** — When a concept feels fuzzy, ask for depth
4. **Spaced repetition** — Return in 2–3 days; session tracking ensures fresh questions
5. **Mix units** — After mastering individual units, try "All Units" mode

### 📊 Study Strategies
- **Baseline:** Take all 515 questions to see strengths/weaknesses
- **Focused:** Spend a week on Unit 2 (largest, most tested)
- **Before exams:** Use Unit 4 (professional/global values) for synthesis
- **Final review:** Switch between units randomly in all-units mode
