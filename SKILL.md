# Value Education Personal Tutor

Your interactive study companion for the Value Education question bank. One question at a time, instant feedback, and concept explanations designed to stick.

## How to Use

### Getting Started

Simply ask to start:
- **"Quiz me"** or **"Test me on value education"** → Random mix from all units
- **"Unit 2 questions"** or **"Quiz me on unit 1"** → Filter by a specific unit
- **"Start a practice session"** → Begin with all questions

### During a Quiz

1. **You see** the question with options A–E
2. **You pick an option** (e.g., "B" or "Option C")
3. **Instant feedback:**
   - ✅ **Correct!** Concept explanation + memory trick
   - ❌ **Not quite.** What the right answer is + why + memory device
4. **Progress tracker** shows your session score at the bottom

### Commands (Anytime)

| Command | What it does |
|---------|-------------|
| Any option letter (A–E) | Submit your answer |
| "Next" or "Continue" | Move to the next question |
| "Shorter" | Make explanations briefer |
| "Explain more" | Go deeper on the concept |
| "Score" | See current session progress |
| "Unit 3" | Switch to a different unit |
| "All units" | Go back to mixed questions |
| "Exit" | End the session |

## Learning Features

### Memory Tricks Built In
Each explanation includes a **mnemonic or visual anchor** to help retention—e.g., "Think of **S**ena: **S**elfless, **S**ervice, **S**ociety."

### Session Tracking
- Tracks which questions you've seen **this session** (no repeats)
- Shows your score: Questions Correct / Attempted
- Resets when you start a new session or switch units

### Adjustable Difficulty
- Default explanations are **concise** (aligned to your learning style)
- Ask **"Explain more"** for deeper context
- Ask **"Shorter"** for just the key concept

### Unit Filters
Study one unit at a time or mix them:
- **"Unit 2"** → Only Unit 2 questions
- **"All units"** → Shuffle across all 5

## Pro Tips

✅ **Focus strategy**: Tackle one unit per session. You'll build stronger retention.  
✅ **Review mode**: Revisit a unit you scored below 70% on within 24 hours.  
✅ **Explain more**: When a concept feels fuzzy, ask for the deeper explanation—it'll anchor better.  
✅ **Spaced repetition**: Return to the tutor in 2–3 days; the session tracker ensures you get new questions.
